# Consumable Items

## Purpose

This document defines the consumable produce represented by the current harvestable sprite set.

Asset naming should follow the existing convention:

`CsmItem_<ConsumableName>`

A consumable can later also be used as a crafting ingredient. Being craftable does not require duplicating it as a `Material`.

## 5. Current Greenvale Consumable Scope

Only one harvested consumable needs to be introduced during the current Greenvale tutorial:

`Cherry`

This keeps the tutorial focused:

1. find the Cherry Tree;
2. harvest it;
3. obtain a Cherry;
4. learn the Consumable Item system;
5. use the Cherry to restore Health.

The other fruits, berries, and crops form the content catalogue for later areas rather than being introduced all at once.
