# Harvest-Sourced Consumables

## Purpose

This document records the subset of **Consumable Items obtained through harvesting**.

The global Consumable Item catalogue now belongs under:

`Documents/GameContent/Items/Consumables/`

This harvesting document should not attempt to define every food item in the game, because future consumables may come from fishing, farming, enemies, containers, vendors, cooking, quests, or other systems.

## Greenvale Scope

Only one harvest-sourced consumable is currently required for Greenvale Border Path:

`Cherry`

Tutorial relationship:

`Cherry Tree -> Cherry -> Consumable Item tutorial -> Health restoration`

Other foods in the global Consumable catalogue should not be added to Greenvale merely because their sprites already exist.
